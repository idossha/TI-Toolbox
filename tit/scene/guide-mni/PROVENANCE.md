# MNI guide scene — provenance and licence

Everything in this directory is **derived data**, generated by
`tit/scene/guide_build.py --atlases mni --guide-id mni` and then frozen. Nothing here is rebuilt at
runtime, and no source dataset is redistributed as such.

It is the anatomy the targeting panes draw when a row's ROI is in **MNI space**
(`docs/dev/DECISIONS.md § 2026-09-17`). Its `space` is still `guide-ras`: the pane names regions on
it and never emits a coordinate from it.

## Source — the head

| Field | Value |
|---|---|
| Dataset | SimNIBS **example dataset**, subject `MNI152` (the MNI152 template T1 and its charm head model) |
| Upstream | <https://github.com/simnibs/example-dataset> (releases) |
| Fetched with | `simnibs_python -m tit.examples --project <scratch> mni152/headmodel` (`tit/examples/catalog.json`, store `idossha/ti-toolbox-example-data` release `v1`, sha256-pinned) |
| Generated | 2026-09-17, in `idossha/ti-toolbox:v3.0.0` (SimNIBS 4.6) |
| Licence | GPL-3.0-or-later — the same vetting as `tit/scene/guide/PROVENANCE.md`; TI-Toolbox is GPL-3.0, so redistributing GPL-3.0 derived assets is permitted |

`surfaces/skin.*` and `surfaces/gm.*` are decimated display surfaces extracted from that head
model's mesh. The mesh itself, the `m2m_` directory and every volume are **not** packaged.

## Source — the atlases

Each `surfaces/atlas-<file>.*` is a marching-cubes surface of one packaged MNI label volume in
`resources/atlas/`, and `labels/<file>.*` carries its per-vertex label values. The volumes
themselves are the ones already shipped there; nothing new is redistributed by this directory that
`resources/atlas/` does not already redistribute. **`resources/atlas/README.md` is the licence table
of record.**

The Morel thalamus surfaces that were packaged here on 2026-09-17 were removed the same day, with
the atlas itself (CC BY-NC-SA; `resources/atlas/README.md § Not shipped`). The guide was then
rebuilt with the command under *Regenerating* (same head model, same builder): `skin`, `gm`, the
CIT168 and MASSP surfaces and every net came out byte-identical (sha256 unchanged in
`manifest.json`), and the three atlases above were added.

`MNI_Glasser_HCP_v1.0.nii.gz` is **not** packaged here: it is a 360-parcel cortical parcellation and
`tit/scene/volume_surfaces.py` draws at most 256 regions. It is still selectable in the ROI picker,
which reads the atlas catalog rather than this guide; it simply cannot be *clicked* in the pane.
`Schaefer2018_400Parcels_7Networks_order_FSLMNI152_1mm.nii.gz` is skipped for the same reason
(400 parcels); it is selectable in the picker and not clickable in the pane.

## Space

The head is the MNI152 template, so these millimetres are MNI152 millimetres — but note that the
atlases packaged on it are not all defined in the *same* MNI152: CIT168 is MNI152NLin2009cAsym,
MASSP is MNI152NLin2009bAsym, while the head itself is MNI152NLin6Asym (which is also the template
SimNIBS's `mni2subject` warps assume). The measured global difference between the NLin6Asym and NLin2009cAsym
templates is ~1.3 mm (brain-mask centroids), with larger local differences at small deep nuclei.
`resources/atlas/README.md` carries the table and the recommendation.

## Regenerating

```bash
simnibs_python -m tit.examples --project <scratch> mni152/headmodel
simnibs_python -m tit.scene.guide_build \
    --project <scratch> --subject MNI152 \
    --out /ti-toolbox/tit/scene/guide-mni \
    --label "MNI152 template" --atlases mni --guide-id mni
```

Packaged total: 25.97 MB (the 21 MB Ernie guide plus three more atlases).
