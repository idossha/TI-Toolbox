## Open issues for the next workflow

See `dev/notes/v3-pipelines/s1-notes.md` for the two runner bugs fixed here (with tests) and the
full list; the ones that need another lane:

1. **`stats`, `blender` and `tools` jobs report zero artifacts.** The `stats` job wrote 9 files
   (`pvalues_map.nii.gz`, `difference_map.nii.gz`, `analysis_summary.txt`, …) and
   `GET /api/jobs/<id>` returned `artifacts: []`, so the Results view has nothing to link.
   Evidence: job `60727ba738144204`.
2. **Cancelling any job writes a PETSc/MPI crash block into its log** — `[0]PETSC ERROR: Caught
   signal number 15 Terminate` plus `application called MPI_Abort(MPI_COMM_WORLD, 59)` — even
   for `blender`, which runs no solver. A user who cancels sees what looks like a crash.
   Evidence: jobs `b9632d9056de45c1`, `169bb37396634a31`.
3. **An analysis written outside `Analyses/{Mesh,Voxel}/` is invisible.** The analyzer honours
   any `output_dir`; `tit.catalog.analyses` (`tit/catalog.py:840`) only scans those two
   directories, so `GET /api/catalog/analyses` returns nothing for it.
4. **`nilearn`'s default `min_cutoff = 0.3` V/m is above the data.** ernie's MNI-space
   `L_Insula` `TI_max` peaks at 0.138 V/m, and the job dies with `nilearn visuals failed:
   minvalue must be less than or equal to maxvalue`. The UI's default does the same.
   Evidence: job `287e3e0c2eb94134`.
5. **`GET /api/project` returns `host_path: null`**, so a client cannot map the container paths
   every artifact carries onto the host without `docker inspect`.
6. **No OpenAPI document is served at runtime** (`tit/server/app.py` passes `openapi_url=None`),
   so a client cannot discover `JobKind` or the routes from a live server.
