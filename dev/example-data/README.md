# Example data — the store lives in its own repository

The content-addressed assets `tit/examples/catalog.json` points at, and the `stage.py` /
`publish.sh` that build and upload them, are in
**<https://github.com/idossha/ti-toolbox-example-data>** (release `v1`, every asset named by its
own sha256). Add a sample there, then commit the `--write-catalog` change to
`tit/examples/catalog.json` here.
