## Goal

Replace the PyQt5 GUI (runs inside the container, needs X11 for everything) with an Electron +
TypeScript app on the host that talks to a Python job server (`tit.server`) inside the container.
Scientific logic stays in `tit`; the UI never computes. Live monitoring and safe parallel jobs are
the two hard requirements.

## Rules every PR is judged against (from the design page)

R1 science lives in `tit` · R2 decisions are typed JSON from the config dataclasses · R3 anything long
is a job · R4 viewing is a declarative ViewSpec (rendered by Freeview/Gmsh today, an internal viewer
later) · R5 the shell only does host things · R6 the GUI process needs no display (viewers do, for now).
