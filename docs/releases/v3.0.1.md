# Release v3.0.1

**Release Date**: September 23, 2026

A patch release for everyone on v3.0.0. Install the new desktop app; it downloads the matching
image (`idossha/ti-toolbox:v3.0.1`) on its next start. Projects, saved scenes and results from
v3.0.0 open unchanged.

#### Highlights

- **A notification when a job finishes.** The desktop app shows a system notification naming what
  finished and for whom, e.g. **Simulation finished** · _sub-101 · montage L_Insula_. A new
  **Notifications** card in **Settings → Project** turns them off, limits them to failures, or picks
  the sound: Pulse (default), Chime or Tick, the system sound, or none. **Send test notification**
  shows a sample banner and tells you why if it did not appear.
- **Apple Silicon Macs download the image again.** On an M-series Mac with no cached image, v3.0.0
  could stop with "no matching manifest for linux/arm64/v8". The app now always pulls the Intel
  (linux/amd64) image, which runs under emulation as before, and the image is published as a plain
  single-platform image so older app builds download it too.
- **Explode an MNI atlas, and pick one hemisphere.** In MNI space the Optimizer's and Analyzer's 3D
  pane has an **Explode** button that fades the scalp and pulls the atlas regions apart so deep
  structures can be seen and clicked. The CIT168 and Harvard-Oxford cortical atlases now list each
  structure per hemisphere (**CIT168 subcortical nuclei (left/right)**, **Harvard-Oxford cortical,
  lateralized**), so choosing "Putamen" selects one side, not both. A saved configuration naming the
  old bilateral atlas files stops with a message naming the replacement.
- **Run pages keep the Jobs table readable.** The Jobs panel stays between 640 and 800 px wide and
  the Terminal/Scene pane keeps at least 400 px; below a 1140 px wide window the page stacks them.

#### Also fixed

- Pressing **Run** on a job whose outputs already exist opens the **Skip / Replace** dialog on the
  first press, and **Skip** queues only the new jobs.
- A scene re-saved in TetraVox gets a fresh thumbnail in **Viewer ▸ Saved scenes**, and its info
  card drops repeated rows.
- After an update the app always loads the new interface instead of a cached copy.
- The Windows app finds Docker Desktop's `desktop-linux` context, and TI-Toolbox installs and
  updates its own TetraVox copy on every platform without touching yours.
- A **CPU limit** in **Settings → Project → Execution** (70 % of your cores by default) caps what
  running jobs share; each product runs one job at a time.

The full list is in the [Changelog](https://idossha.github.io/TI-Toolbox/releases/changelog/).
