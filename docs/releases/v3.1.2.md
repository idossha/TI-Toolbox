# Release v3.1.2

**Release Date**: October 22, 2026

A patch release that fixes many edge cases and greatly extends the automated test suite, so the
app refuses what it cannot run and its outputs say what was really run.

**Update:** install the new desktop app; it downloads the matching image
(`idossha/ti-toolbox:v3.1.2`) on its next start. Update both together, since the image carries the
server the app talks to. If you run the image yourself, pull it again:
`docker pull --platform linux/amd64 idossha/ti-toolbox:v3.1.2`.

#### What changed

- **Edge cases are refused before a job runs.** Settings and inputs that used to fail only after
  a job had started are now refused when you submit, and the page shows the reason.
- **Outputs are checked for being right.** Reports, EEG caps, Results entries, analysis folders
  and group maps were checked against what was run and corrected where they were wrong.
- **A much larger test suite and CI.** Many more automated tests and CI checks now guard these
  cases.
- **Image fixes.** SimNIBS warps vector fields (E, J) to and from MNI space again, and the Nilearn
  atlases ship in the image, so atlas outlines draw offline.

The full list is in the [Changelog](https://idossha.github.io/TI-Toolbox/releases/changelog/#v312--october-22-2026).
