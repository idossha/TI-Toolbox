# Release v3.1.1

**Release Date**: October 20, 2026

A patch release. Install the new desktop app; it downloads the matching image
(`idossha/ti-toolbox:v3.1.1`) on its next start. Update both together: the image carries the server
the app talks to. Projects, saved scenes and results from v3.1.0 open unchanged; subjects that use
one of the four corrected EEG caps need that cap re-applied (see **Fixed**).

#### Additions

- **The EEG caps panel.** Turn it on in **Settings ▸ Extensions ▸ EEG caps**. Pick a subject, tick
  the caps you want and press **Apply selected**: each cap is placed on the subject's existing head
  model exactly as charm does at the end of a head-model build, in a few seconds, without rebuilding
  the head model. You can also add your own MNI cap CSV to the project. The table shows which caps
  are on the subject and when each was applied, and asks before replacing one. Click a net to see
  it on the subject's scalp with each electrode's spacing and distance to the scalp, a warning when
  electrodes collapse onto each other, and an optional second net to compare. See
  [EEG Caps](https://idossha.github.io/TI-Toolbox/wiki/eeg-caps/).

#### Fixed

- **GSN-HydroCel-128, BioSemi-64, BioSemi-128 and BioSemi-256 caps:** these four caps were in the
  wrong coordinate frame, so a head model built with them had their central electrodes collapsed
  onto one point, leaving a hole in the net (43 electrodes of the GSN-HydroCel-128). They are now
  in MNI space and sit on the head. A head model built before this release keeps the wrong
  positions: open **EEG caps**, tick the affected cap and press **Apply selected** (choose
  **Replace and rerun** when asked) — or **Re-apply all** — for each subject that uses it.
  Simulations and optimizations that used one of these nets should be re-run afterwards. Other nets
  are unchanged.
- **Simulation report:** the report of a simulation was not written, for every subject, with
  `matmul: Input operand 1 has a mismatch in its core dimension 0`. It is written again; simulation
  outputs are unchanged.

The full list is in the [Changelog](https://idossha.github.io/TI-Toolbox/releases/changelog/).
