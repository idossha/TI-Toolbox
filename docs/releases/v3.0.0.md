# v3.0.0 — September 20, 2026

v3 introduces a new desktop interface for managing projects, running workflows, and viewing results.
The v3.0.0 release is tagged. Installer and container publication is tracked on the
[GitHub release](https://github.com/idossha/TI-Toolbox/releases/tag/v3.0.0); downloads become available when the release workflow finishes.

## Highlights

- **A clearer project workspace.** Overview shows subject readiness, storage, and activity;
  Jobs keeps progress and logs together; Results brings your outputs into one browser.
- **Integrated visualization.** View volumes and meshes in Tetravox, place electrodes on a subject’s
  scalp, and preview selected targets alongside the Simulator, Optimizer, and Analyzer.
- **More flexible targeting.** Import your own NIfTI masks in subject or MNI space for optimization
  and analysis, with read-only target previews.
- **Faster segmentation with hardware-aware setup.** FastSurfer uses an accessible NVIDIA GPU in
  Docker. Apple Silicon users can enable native GPU support in **Settings → System**, with an
  explanation and permission prompt before installation. Thread preferences apply across projects.
- **Scripted workflows.** Work in notebooks and enable optional extensions as needed.
- **Simpler setup.** The desktop application manages the core container and integrated viewer;
  XQuartz and other X11 setup are no longer required.

#### Upgrading from 2.x

- Back up your project, then follow the [installation guide]({{ site.baseurl }}/installation/).
  The core image is now `idossha/ti-toolbox:v3.0.0`.
- Existing project directories, head models, simulations, and optimization outputs remain readable.
- FastSurfer provides DKT-atlas segmentation. Choose optional FreeSurfer when you need full
  reconstruction or its subregions; see [Pre-processing]({{ site.baseurl }}/wiki/pre-processing/).
- Script users: `PreprocessConfig.run_recon` becomes `run_fastsurfer`;
  `parallel_recon`, `parallel_cores`, and `run_subcortical_segmentations` are removed.
  The `tit.calc` API from v2.5.0 is unchanged. See the [Changelog]({{ site.baseurl }}/releases/changelog/) for details.
