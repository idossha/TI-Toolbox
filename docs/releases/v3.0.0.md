# Release v3.0.0

**Release Date**: September 20, 2026

v3 introduces a new desktop interface for managing projects, running workflows, and viewing results.

#### Additions

- **A clearer project workspace.** Overview shows subject readiness, storage, and activity;
  Jobs keeps progress and logs together; Results brings your outputs into one browser.
- **Native visualization.** Open volumes and meshes in a separate TetraVox window, place electrodes on a subject’s
  scalp, and preview selected targets alongside the Simulator, Optimizer, and Analyzer.
- **More flexible targeting.** Import your own NIfTI masks in subject or MNI space for optimization
  and analysis, with read-only target previews.
- **Faster segmentation with hardware-aware setup.** FastSurfer uses an accessible NVIDIA GPU in
  Docker. Apple Silicon users can enable native GPU support in **Settings → Pre-processing**, with an
  explanation and permission prompt before installation. Thread preferences apply across projects.
- **Scripted workflows.** Work in notebooks and enable optional extensions as needed.
- **Simpler setup.** The desktop application manages the core container and native viewer setup;
  XQuartz and other X11 setup are no longer required.

#### Scientific corrections

These fixes concern specific analysis conditions, not a general change to the simulation model.
Existing results outside the listed conditions do not need to be regenerated for these fixes.
The SCI identifiers match the regression tests in `tests/numerical/`.

| Fix                                   | Affected versions and workflow                                     | Action for existing results                                                                                                                                                                                             |
| ------------------------------------- | ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SCI-01: cluster sign/null handling    | 2.2.3–2.5.0, two-sided or left-tailed cluster tests                | Re-run; right-tailed (`greater`) tests are unaffected by this fix                                                                                                                                                       |
| SCI-02: common-grid validation        | 2.3.0–2.5.0, group images with differing affines                   | Align to a common grid and re-run; already matching grids are unaffected                                                                                                                                                |
| SCI-03: voxel focality units          | 2.3.0–2.5.0, voxel `focality_*_area` values                        | Divide old values by 10 to obtain cm³; mesh values are unchanged                                                                                                                                                        |
| SCI-04: sampled permutation estimator | 2.2.3–2.5.0, sampled permutation p-values                          | Use `(b+1)/(m+1)` with original exceedance/permutation counts. At 1,000 permutations the shift is at most 0.001; re-run borderline results or if counts are unavailable. SCI-01 also requires a re-run where applicable |
| SCI-05: affine-based geometry         | 2.3.0–2.5.0, sheared image affines                                 | Re-run those analyses; orthogonal grids are unaffected                                                                                                                                                                  |
| SCI-06: zero-variance handling        | 2.2.3–2.5.0, degenerate voxel contrasts                            | Re-run; non-finite statistics are now identified and excluded from cluster inference rather than reported as null effects                                                                                               |
| SCI-07: carrier exposure definitions  | Unreleased shared-carrier development code only                    | No action for released 2.x outputs; shipped positional wiring is unchanged                                                                                                                                              |
| SCI-08: envelope conditioning         | 2.4.0–2.5.0, very weak modulation                                  | No action; the precision improvement is below the FEM input noise floor                                                                                                                                                 |
| SCI-09: singleton pooled variance     | 2.2.3–2.5.0, unpaired comparisons with one subject in either group | Re-run to obtain the correct t/p maps; very small cohorts still limit attainable significance                                                                                                                           |

Exposure-metric definitions and limitations are in
[Analyzer: safety metrics]({{ site.baseurl }}/wiki/analyzer/#safety-metrics).

#### Upgrading from 2.x

- Back up your project, then follow the [installation steps]({{ site.baseurl }}/installation/#install).
  The core image is now `idossha/ti-toolbox:v3.0.0`.
- Existing project directories, head models, simulations, and optimization outputs remain readable.
- FastSurfer provides DKT-atlas segmentation. Choose optional FreeSurfer when you need full
  reconstruction or its subregions; see [Pre-processing]({{ site.baseurl }}/wiki/pre-processing/).
- Script users: `PreprocessConfig.run_recon` becomes `run_fastsurfer`;
  `parallel_recon`, `parallel_cores`, and `run_subcortical_segmentations` are removed.
  The `tit.calc` API from v2.5.0 is unchanged. See the [Changelog]({{ site.baseurl }}/releases/changelog/) for details.
