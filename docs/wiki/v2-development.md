# V2 development & testing (deprecated)

This archive preserves developer references for legacy v2 installations. The PyQt5 GUI and its
extension API were removed in v3.0.0. Use these instructions with the corresponding v2 source
checkout; historical commands and paths are not a guide to the current application.

- **[V2 testing pipeline]({{ site.baseurl }}/wiki/testing-pipeline/)** — pytest fixtures, test images, and CircleCI configuration documented for v2.
- **[V2 PyQt GUI]({{ site.baseurl }}/wiki/gui/)** — the former tabbed interface and its implementation.
- **[V2 Qt extension API]({{ site.baseurl }}/wiki/extension/#architecture-historical)** — extension discovery, metadata, installation, and development examples.
- **[V2 gallery]({{ site.baseurl }}/gallery/v2/)** — preserved screenshots for legacy users and developers.
- **[V2.5.0 release notes]({{ site.baseurl }}/releases/v2.5.0/)** — version-specific changes.

For v3, start with the [Desktop Application]({{ site.baseurl }}/wiki/desktop-app/),
the [Python environment]({{ site.baseurl }}/wiki/python_env/), and the
[current testing guide](https://github.com/idossha/TI-Toolbox/blob/main/docs/dev/TESTING.md).
